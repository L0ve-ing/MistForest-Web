# 雾隐之森网页版 · 1.1.8-web.2

公网试运行：[打开雾隐之森](https://mistforest-web.onrender.com)。电脑和手机打开同一个网址，一人创建房间，其他人输入房间号或打开邀请链接加入；使用公网网址时，无需连接同一 Wi-Fi。

点击上方部署按钮，可在自己的 Render 账号按免费套餐创建服务。配置关闭了后续代码推送的自动部署，需要更新时在 Render 主动执行部署，以减少进行中对局因更新中断。

GitHub 仓库名称：`MistForest-Web`。根目录的 `render.yaml` 提供 Render 免费试运行配置：Docker、新加坡区域、单实例、最多 4 个房间。可在 Render 连接本仓库的 `codex/render-deploy-20261104` 分支，按 [Render 部署说明](docs/Render部署.md) 创建服务。公网接口已验证；不同网络的电脑和手机实机联机仍需实际验收。

基于原版 v1.1.8 和精简候选 `5398741` 的独立网页版。网页重建界面与房间接入，复用原 C++ 裁判和美术；原生 Windows 游戏源码仍保留，未修改规则核心。

支持 2–4 人建房、房间号加入、每方 1–2 个不同职业、13 职业选择、秘密部署、合法动作与参数选择、胜负、重开、战报和自己的历史视角。桌面采用战场信息、棋盘、操作三栏；手机窄屏上下布局，所有必要功能可用点击完成。网页玩家之间联机，与旧 EXE 的 TCP 协议不互通。

web.2 补齐原版素材的播放：14 种角色外观的待机、行走与待机变化，7 张特效图集的 43 行素材，分阶段攻击与受击反馈，判定、私人报告和回合情报，以及轻量散雾过渡。特效与己方移动路径直接复用原 C++ 表现层的受限视图判定；原 PNG 未重绘。可选择完整或简化动画、播放速度，也可跳过演出。历史滑条目前仍显示静态的本人历史视角，尚未复刻原生程序的全部复盘界面。

## 启动

Windows 运行包：完整解压后双击 `start-web.cmd`。包内已带 Node.js 与裁判程序，不需要安装开发工具。服务器窗口保持开启，在浏览器打开窗口打印的地址。

从源码构建：安装 Node.js 22 或更新版本，以及支持 C++17 的 g++。无需 npm 依赖安装。

```text
node scripts/build-web.mjs
node scripts/start-web.mjs
```

默认监听 `0.0.0.0:8787`。当前电脑打开 `http://127.0.0.1:8787`；其他设备使用运行窗口列出的实际局域网地址。手机和电脑须能通过同一路由网络互访；VPN/虚拟网卡地址不一定可用，电脑首次防火墙提示应按实际网络选择允许。手机的 `127.0.0.1` 指向手机自身，不能用来访问电脑服务器。

刷新会恢复本标签页的席位；切后台返回或连接中断后重新拉取当前局面。会话令牌只保存在本标签页，不与其他玩家分享。服务器停止/重启后房间清空；没有上线账号系统或服务重启后的持久恢复。默认最多 8 个房间，关闭且 2 小时无操作的房间自动回收。

可通过环境变量 `PORT`、`HOST`、`MAX_ROOMS` 调整监听地址、端口和房间上限。只在本机访问可设置 `HOST=127.0.0.1`。公网服务使用 Render 提供的 HTTPS 地址；自己电脑上启动的服务仍按本地或局域网方式访问。

## 工程

- `web/public/`：浏览器界面，原生 HTML/CSS/JavaScript。
- `web/public/presentation.mjs`、`presentation.css`：原版图集播放、己方移动、攻击反馈与响应式战斗布局。
- `web/server.mjs`：房间、认证、串行调度、推送、重连与资源服务。
- `web/referee.cpp`：C++ 裁判桥，输出玩家受限视图与合法动作。
- `scripts/build-web.mjs`、`start-web.mjs`：构建和启动，不依赖测试或网页框架。
- `src/`、`maps/`：原版规则、AI、原生界面、美术与地图。
- `docs/网页版使用说明.md`：游玩、手机访问和后续部署说明。

通信使用同源 HTTP 动作提交和 SSE 状态推送，不额外引入 WebSocket 库。玩家身份、局号和 revision 在服务端绑定；动作请求有去重编号，陈旧或非本人动作被拒绝。每个房间独立裁判进程；浏览器只接收 `Game::view(本人)`，不接收完整 Snapshot 或原始 Event。图鉴内容直接来自现有规则。
