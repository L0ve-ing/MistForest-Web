# 角色立绘来源与使用

14张PNG来自用户工作区提供的“角色立绘_最终 (2).zip”，按明确授权接入游戏。图片原始字节未修改；manifest.json记录原包及逐图SHA256、资源编号、包内PNG索引。未引入另一个分支尚在制作的烬待机动画。

隐狼狼形为资源2105、人形为2113；形态值0为人形，1为狼形。资源2109使用包内流萤立绘，按用户最新要求显示于“祝融”，不修改角色名、火焰技能、机制或数值。其余编号2100+角色枚举值。

portraits.rc将素材嵌入程序，ui/portraits.inc从自身模块资源读取、缓存透明图并在运行时适配完整图/头像区域。资源缺失时回退既有徽章；正常构建通过原生测试保证14项均存在。素材不要求随EXE单独分发，棋盘仍使用既有矢量徽章。
