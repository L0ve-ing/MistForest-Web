# 雾隐之森 v1.1.8 使用说明

启动与设置：开场雾气向两侧散开并逐渐隐去，点击或按键可跳过；普通页面切换使用较轻的雾效。大厅中选择人机教学、基础版或联机后，进入对应的对局设置页。模式卡片用于选择职业对战或 3×3 无限侦察；人数用上下箭头或人数区域滚轮在 2—4 人间调整。选择 2 对 2 会自动设为并锁定 4 人，切回各自为战后可继续调整。职业模式可选每人 1／2 名角色，侦察模式固定 1 名。

对局设置右侧预览当前地图，并提供默认／自定义地图及编辑入口；人机教学额外显示电脑风格和新手／角色练习入口。底部汇总本局配置。本地及人机点击“选择角色与站位”继续，联机点击“创建／加入房间”继续。浅绿与标记表示已选项，深青绿按钮表示主要下一步，灰色表示当前不可用。

2—4名玩家，单角色或双角色，4人可组队。每次玩家行动回合只允许一名角色主动行动。每名存活玩家完成一次行动回合为一轮；直接攻击上限按受击对象所属玩家的回合开始至下次回合开始计算，取最高强度，只补差额；在该玩家回合开始重置。角色、每名士兵、建筑、玫瑰独立记录，移动不清空；打空不赋予免伤；燃烧独立结算，绝影保留必杀。

- 点击己方小头像、Q顺序切换，角色区滚轮换人；第一项实际行动后锁定。未提交的预选可以清空，不会锁定。
- W移动，E/R/T及后续顶排键选择攻击和技能，以卡片标注为准。
- 长生剑点相邻格选方向，U切换包含自身；前方两格或自身加相邻格，每次1剑气，阻挡会截断。
- 空格执行；S结束回合，攻击后秘密落点阶段为留在原地。
- B切换批量，V清空路径；Z堡垒、C城墙或长城、X拆除。
- 参数1/2/3；参数区滚轮调整。飞剑按距离自动扣剑气，原地0消耗，放剑后可立即回剑并使用额外普攻或移动。
- A上一回合，D下一回合，F最新；战报区滚轮浏览，手动历史不会自动跳转。
- H查看当前角色技能；点击当前或敌方头像查看介绍，己方小头像右键查看。查看时暂停播放，Esc关闭。
- 线墙L形连接点：擦过外侧可以攻击，穿过两条墙臂之间会被挡。墙臂朝上和右时，左上↔右下可攻击、右上↔左下不可；旋转后同理。连续直墙、T形和十字连接点仍阻挡攻击。

其他玩家的行动、文字、特效和反馈按顺序播放，全部显示完才能操作。教学提供99个真实步骤、伤害说明、示范、重试和独立练习。
生命数值及机制见角色技能介绍。联机双方需同为1.1.8，协议10108拒绝旧版本及旧恢复文件。终局完整回放公开所有位置，局内视图仍隐藏敌方站位。
任务预览不等于正式发布；正式程序须从最新main构建并记录版本、提交和哈希。

隐狼每个己方回合只能在行动前变身一次，无跨回合冷却；减伤和临甲规则见技能介绍。

技能特效：攻击与技能按角色分别呈现，种玫瑰有花苞绽开，盛放有荆棘和花瓣，玫瑰摧毁有凋落；长生剑直刺、飞剑和召回，白墨霰弹与冲刺等均区分。默认 1.0× 速度下单段约 0.6 秒，连续攻击按公开攻击格分段。动画结束后保留原有驻场标志，战报文字和操作锁定仍按行动播放推进。查看技能、离开确认和播放设置会暂停实战特效；本人受限回放不显示秘密位置，重复绘制不会重启动画。

角色立绘：选角区、角色介绍和局内技能弹窗展示完整人物，战斗右侧与其他头像使用立绘头像，棋盘内使用透明像素角色动画。隐狼介绍页可同时看到两种形态，战斗显示当前形态。祝融暂用流萤立绘，名称、火焰特效和所有技能机制保持不变。立绘嵌入EXE，移动程序或改变工作目录无需另带素材文件夹。



棋盘显示：坐标位于格子左上角，角色名字放在底部，中央用于放大的原生角色图。当前角色保留脚底光环，长城守卫军分别标记士兵1／2／3。布置角色时，选中格子显示半透明角色预览，确认后正常显示；切换落点时预览同步移动。

森林地形：草地、落叶和上层植物采用协调的自然配色，坐标、名字与可见角色附近局部减淡。湖泊与漩涡保留蓝绿水面及固定苔石岸边，漩涡水纹贴合岸圈内部。方墙占据整格，线形墙沿格子边界连接；城墙、堡垒、长城和废墟使用不同石材轮廓。装饰只使用公开地形和可见角色信息，隐藏敌人的真实位置不影响格子外观。

战场动作：普通移动沿已提交的路径逐步显示，批量操作按各步推进；冲刺沿直线，骑士跃击带弧线，随影跨边移动从一侧穿出、从另一侧穿入。攻击、受击和退场使用原生角色图的前倾、闪烁、后仰与淡出反馈。多人同格分别排布。

骑士沉默在中心及四个相邻格显示，不包含斜角格；已知且受影响的角色显示状态标记。随影选择敌人时有虚线预选标记，确认缠绕后变为紫色印记；隐藏目标只显示头像标记，不暴露棋盘坐标。

播放设置：在页面上方打开“播放设置”，选择完整／简洁动作及 0.8×、1.0×、1.25× 速度。设置期间暂停播放；新速度从下一项行动或下一步回放开始生效，动作、特效和战报同步调整。简洁模式保留移动路径、技能范围与命中提示，减少身体晃动和粒子。设置保存到程序旁的 mist-presentation.ini。回放同样显示路径和身体反馈，受限回放继续隐藏未知位置。

角色动画沿用原生帧素材：骑士行走、隐狼人形和狼形特殊动画仍以对应待机帧占位；本版没有新增这些缺失帧。
