**v1.1.8 精简与代码优化说明 · 2026-11-03**

原版来源为 `cb4f546eef43520599dbeda7c0ad67e398cc8e73`。本轮基于上一轮本地候选 `0b4665e8e189610b515a96c344a75a6357aa495d`，保留切页绘图缓存、历史读取、批量试算与网络历史追加优化。远程同步仍未成功，本地候选不代表上游已合并。

本轮新增变化：

1. 移除版本套版本的目录结构，展开为 `src`、`maps`、`docs`，只保留当前版本。
2. 测试源码、验证截图、旧构建记录、开发参考图及离线生成工具移出交付工程。验证材料在工程外单独保留，原始版本未删除。
3. 对两份地图逐文件核对 SHA-256 后合并为一份，构建时复制到程序旁边。
4. 新建根目录 `build.ps1`，只构建游戏；CMake 同步独立生产模块，去除测试目标和测试目录依赖。
5. 增加不依赖 Windows 的 `editor::MapEditor`，由它持有草稿、画笔、随机种子和最多 100 步撤销，封装改格、边墙、尺寸变换、清空和随机生成。
6. 编辑器界面只保留绘制、文件对话框及命令适配；页面专属窗口句柄、路径和提示收拢到 `EditorPanel`。总命令入口继续执行共同输入与模态限制。

当前源码包不包含测试或编译产物，`build.ps1` 不需要它们。删除测试主要减少工程内容，不会直接提高游戏帧率。编辑器拆分改善复用和维护边界，本轮未声称因此新增某个帧率收益，也未把整个 UI 改写为平台无关架构。

此前已保留的性能修复：

- 缓存切页及散雾绘制中的重复背景工作。此前固定设置页带雾场景的中位绘制耗时约由 33.2 ms 降至 8.3 ms；它是特定机器和场景的数据，不能代表全部游戏帧率。
- 历史视图直接根据指定 Snapshot 与事件前缀构造，复用玩家信息过滤，避免为了读取一步而复制整个 Game。
- 批量试算只携带当前状态和必要事件上下文，不复制全部旧快照；失败保持原局面不变，成功才追加快照并提交。
- 只读 `canActBatch()` 与预览使用同一试算逻辑，减少外部整局复制。
- 网络历史按新增 revision 追加；完整检查点只有在局号、开局、地图、阵容、就绪状态和动作前缀一致时才复用历史，不一致则重建。完整动作重放校验仍保留。
- 命令编号、30 个动作绑定和快捷键统一到无 Win32 依赖的 `command_catalog` 模块；移除四个已无引用的旧裁判字段，包括一份多余 Snapshot。
