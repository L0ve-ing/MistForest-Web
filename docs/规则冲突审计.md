# v1.1.8 规则结算说明

所有存活玩家各完成一次回合为一轮；各对象在其所属玩家回合开始清空直接受击记录，持续至该玩家下一次回合开始；整轮边界不再清空对象记录。格子攻击强度仅作为公开攻击历史，不参与免伤计算。

直接攻击对每个实际受击对象计算新增强度：max(0, 本次强度 - 该对象当前受击周期最高强度)。移动或更换攻击者不会清空记录。友伤免疫、建筑保护及座狼不能伤建筑的情况不更新被保护对象记录；打空没有对象记录。

易伤使攻击强度增加0.5后参与对象上限计算；燃烧也受易伤影响。新增强度先经过形态减伤，再扣护甲、临甲和生命。建筑使用自身实际基础攻击强度（白墨翻倍）；玫瑰及角色分别计算。建筑在本次攻击开始时保护角色，拆掉后续攻击才可命中内部角色，绝影例外。

守卫军每名士兵独立记录直接攻击强度。直接攻击的新增伤害按原列阵规则分担；分担造成的失血不写入其他士兵的直接受击记录，因此分担不等同于那些士兵已经承受过一次直接攻击。燃烧不平摊、独立于直接上限，绝影不平摊并保持必杀。

隐狼每个己方回合行动前可变身一次，无跨回合冷却；同回合不得反复切换，行动后及沉默期间不得切换。临甲不叠加，下个己方回合开始清除。

联机检查点与恢复通过确认动作日志重建裁判及对象记录；协议10108拒绝旧规则。敌方位置保持隐藏；公开生命、防御和受击强度不包含当前位置。批量预览只预测己方资源及公开对象，不提前检测隐藏命中。


重骑冲锋、骑士倾轧和玄甲士刺击为普攻，沉默保留；其他主动能力仍受沉默限制。骑士沉默与易伤按施放者下一回合开始解除；随影附骨的暂停仍于受影响随影下一回合开始结束。仅游猎前两项有跨回合冷却。

阿尔法每次普攻命中回复0.5；嗜血当回合的溢出转为临时血量。伤害先消耗临时部分，剩余部分在己方下一回合开始移除，不会重复扣除已消耗部分。

长生剑原地留剑0消耗，投出按距离消耗；飞剑占用本回合正常行动，不能同回合再次放剑，允许立即回剑。回剑按当前距离消耗，不返还投剑花费，一次额外额度可用于普攻或移动。驻场剑降低回合末回复上限；原地立即放回不会扣剑气。
