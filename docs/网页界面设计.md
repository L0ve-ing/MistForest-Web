# 网页界面取向

延续现有雾隐之森森林、羊皮地图和像素角色，不生成替代美术。主色深松绿 `#254d43`、墨绿 `#133d34`、纸白 `#f7f7ec`、旧金 `#c6ad73`、湖蓝 `#4c8890`，以灰绿分隔线区分操作层级。标题使用系统宋体，信息与按钮使用系统无衬线中文字体，不加载远程字体。

入口以原有森林背景及四个角色立绘作为视觉中心，右侧直接建房和加入。棋局页面以棋盘为主，右侧集中角色、动作和确认；手机竖屏改为棋盘在上、操作区在下，必要按钮至少 44px，不依赖悬停或快捷键。

```
电脑： 顶部游戏名 / 连接状态 / 图鉴
       房间号、席位、邀请
       [ 棋盘与战报                 ] [ 角色 / 动作 / 确认 ]

手机： 顶部游戏名 / 图鉴
       房间号 / 席位
       [ 完整棋盘 ]
       [ 角色 / 动作 / 参数 / 确认 ]
       [ 可展开战报 ]
```

审视后保留原游戏的浅纸色和绿色，避免另建无关的科技面板。视觉重点只放在森林棋盘；生命、角色编号、坐标和确认按钮保持清晰。迷雾表示敌方信息不可见，不靠高频全屏半透明动画实现。默认无持续背景动画，角色使用原图集首帧，公共攻击格用稳定标记显示；减少动态效果设置继续尊重系统偏好。

布局检查目标为桌面、手机竖屏和手机横屏。电脑模拟尺寸检查不视为真实 Android/iPhone 验收。
