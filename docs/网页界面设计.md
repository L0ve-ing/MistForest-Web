# 网页界面与表现层

web.3 使用已确认的简约方向：浅雾色 `#f2f4f1`、文字 `#283c33`、灰绿 `#64746a` 与操作强调色 `#375e4b`。棋盘居中，常用角色和动作集中在底部；界面不使用背景插画、装饰金边或常驻战报侧栏。系统中文无衬线字体负责标题与信息，不请求远程字体。角色、地形和特效继续读取原 PNG，不重绘素材。

## 布局

桌面采用居中棋盘与底部操作栏。手机竖屏同屏呈现棋盘、角色、动作和确认，横屏将操作放在右侧。操作区高度由 ResizeObserver 读取，棋盘根据实际剩余高度缩放，避免特殊职业参数出现时把确认按钮推出视口。小屏复杂参数在操作区内滚动。地图行列坐标移到棋盘外围；圆点标识合法目标，实线框标识选择，棕色虚线标识公开攻击痕迹。

右上角菜单容纳邀请、在线状态、图鉴、玩法、动画设置与离开。底部“角色详情”展示双方公开生命、己方位置、士兵状态、己方报告及技能入口；对手位置仍隐藏。多动作职业保留常用动作和“更多动作”，从完整列表选中的技能会回到主操作栏。

## 手机战报

`battle-log.mjs` 管理独立于棋盘 DOM 的原生对话框。手机使用底部面板，桌面使用居中面板；标题、筛选、返回按钮和底部历史入口固定，只有记录区域滚动。正文 16px，公开记录与私人反馈同时具有文字标签和不同底色。

- 支持“全部 / 公开 / 仅自己”筛选，记录按步骤分组。
- 用内容、步骤、反馈类型及重复序号标识记录。未读状态按房间及局号保存在 sessionStorage，刷新后继续使用；只把当前筛选中已滚到底部的记录标为已读。
- 读旧记录时保留滚动位置，新记录出现后提供“查看最新”；开关面板保留筛选及阅读位置。
- 棋盘推送和演出刷新不替换面板，因此不会清除当前操作选择或重置正在阅读的记录。
- 服务返回最近 100 条记录；历史滑条仍打开本人当时的静态受限视图，进入历史后提供明确的“回到当前”。

## 原版素材与判定

角色使用原始 14 种外观的图集、脚底注册、帧数及每帧时长。特殊图集属于待机变化，不额外模拟攻击。攻击效果沿用 7 张图集、43 行素材的原生切帧边界和缓存。文字先播报，随后显示动作和攻击反馈，再交回操作。HTTP 返回与 SSE 的同一 revision 去重，恢复席位不重播旧攻击。

攻击类型、公开攻击格、己方受击和移动路径继续由 C++ `makeSkillFx()`、`visibleMovements()` 从本人已提交受限视图生成。不发送 Snapshot、原始 Event 或敌方私人路径；伤害数字仅显示在本人已知受击格。战报直接使用同一个受限视图，没有新增读取敌方信息的接口。

动画预载、切帧缓存和后台暂停沿用 web.2；简化动画与系统减少动态效果偏好仍受支持。素材加载完成或棋盘节点替换时强制完成一次绘制，避免简化模式在限频窗口内漏掉首次角色显示；空闲时不持续绘制。散雾收敛为短暂的透明过渡，地面草纹降低强度，湖泊、墙体、漩涡和建筑保持可区分。

## 验证边界

使用真实本地双席位对局检查战报开关、筛选、已读恢复、推送时滚动保留、历史返回、特殊职业参数与原攻击演出。桌面、笔记本、320/390 竖屏和 844 横屏采用浏览器尺寸模拟；仍需真实 Android/iPhone 与不同网络双设备验收。规则核心、PNG 和协议未修改；完整原生菜单、完整复盘演出与房间持久恢复仍未移植。
