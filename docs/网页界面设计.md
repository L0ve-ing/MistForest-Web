# 网页界面与表现层

延续 v1.1.8 的森林、浅纸面与像素角色，使用现有 PNG，不生成替代美术。深松绿 `#254d43`、纸面 `#fdfaed`、旧金 `#b69a5d`、灰绿分隔线构成界面；标题使用系统宋体，信息和按钮使用系统中文字体，不请求远程字体。

## 布局

桌面沿用原版战斗页面的职责分布：左侧战场信息、中央完整棋盘、右侧角色与动作。行动判定在左侧放大显示，避免把棋盘挤出窗口。详细战报保留在棋盘下方，可以展开并查看自己的历史视角。

手机竖屏依次显示判定与棋盘、角色和操作、战场信息；窄屏动作按钮使用两列。手机和触摸操作不依赖悬停或键盘。主要按钮不小于 44px，必要文字使用明确的文本和边框，不只依赖颜色。

## 原版素材与判定

- 角色读取 `src/assets/characters/manifest.json`，使用原版帧数、每帧时长和图集。特殊图集属于待机变化，不把它们假装成额外攻击次数。
- 特效读取 `src/assets/effects/manifest.json`。43 行效果复用 7 张原 PNG；四幅图代表起势、展开、峰值与收束。大图集沿用原生 `skill_fx_sprite.inc` 的不等距行边界和固定列边界，缓存切帧，避免混入相邻技能或逐帧裁剪导致跳位。
- 攻击类型、可见攻击格、己方受击和移动路径由 C++ 的 `makeSkillFx()`、`visibleMovements()` 从同一玩家的已提交受限视图生成。
- 不发送 Snapshot、原始 Event 或敌方私人移动路径。伤害数字仅在本人已知的受击格显示；范围攻击不会根据敌方生命变化猜测敌人的具体位置。
- 文字先播报，随后显示动作和攻击反馈，再交回操作。HTTP 返回与 SSE 的同一 revision 会去重；初次恢复席位不重播旧攻击。

## 动画与性能

部署阶段在后台准备特效图集；资源切帧只在首次使用时缓存。角色帧只在变化时更新背景位置，效果使用独立画布，不通过每帧重建整页实现。不可见标签页停止动画；简化模式和系统减少动态效果偏好会减少动作，保留判定文字。

散雾使用短时、可点击跳过且不拦截操作的透明过渡。旋转水纹与固定岸边分层显示，地面使用原草纹图集的 4×2 切格；建筑使用原版石墙、堡垒和长城素材。

## 验证范围

已在独立浏览器中检查桌面三栏、完整棋盘、真实攻击素材像素、角色帧变化、判定与胜负显示顺序、刷新恢复和部署预览。320×740、390×844、844×390 未出现横向溢出。游戏规则核心与 PNG 文件未修改。

这轮补齐战斗反馈和演出，尚未逐页复刻原版全部菜单、全部复盘演出或所有技能组合。手机模拟尺寸检查不能代替真实 Android/iPhone 操作与异地双设备验收。
