# 公网游玩

电脑、手机打开 [雾隐之森](https://mistforest-web.onrender.com)。一人创建房间，把房间号或邀请链接发给好友；好友打开同一个网址后加入。公网网址支持不同网络的玩家，无需连接同一 Wi-Fi，也无需在自己的电脑下载、启动服务。

只有在自己的电脑上启动本地服务，并使用局域网地址访问时，才需要同一路由网络互通。房间只属于创建它的那台服务：在其他服务器上输入相同房间号，无法加入原房间。

# 本地与局域网启动

完整解压运行包，双击 `start-web.cmd`，保持打开的服务器窗口运行。当前电脑在浏览器打开 `http://127.0.0.1:8787`。另一位玩家可以用另一个标签页先验证，也可以从同一网络的另一台电脑或手机访问服务器的局域网地址。

创建房间，选择人数、每方角色数量与地图。好友打开相同的游戏地址，填入房间号加入。房间号不是席位凭据：刷新会继续使用当前标签页原来的席位；另一台设备加入则占用新席位。请不要把浏览器会话存储中的令牌发给别人。

点击角色槽选择正在部署的角色，“更换”打开完整职业列表。选中角色后点棋盘放置起点。守卫军分别放置 A/B/C 三名士兵；同一方职业不能重复。点“确认部署”，全部玩家准备后自动开局，先手随机。

轮到自己时，选择一名存活角色，再选动作。圆点表示当前参数下的可用目标；点目标后确认执行。动作较多时点“更多动作”，选择后会在操作栏中显示。参数下拉框用于选择士兵、跟随目标、弹药、另一段墙、玫瑰与落点等。祝融/长生剑攻击后的秘密选择必须完成；“留在原地”也是一次明确选择。动作额度和伤害仍由原版规则裁定，不由网页自行计算。

行动额度用尽时，裁判可能自动推进回合；也可主动结束，放弃剩余次数。原版存在受击周期内直接伤害上限，重复攻击不保证每次都继续扣同样生命。完整职业规则在“角色图鉴”中查看。

点击棋盘右上方“战报”打开记录；手机从底部展开，点“返回棋盘”收起，已选角色、动作参数和目标格不会丢失。数字标记未读条数；已读状态刷新后仍保留在当前标签页。可筛选“全部 / 公开 / 仅自己”，每条私人反馈标有“仅你可见”。向上翻阅时，新战报不会拉动位置，点“查看最新”回到底部。重新打开战报会保留上次的筛选和阅读位置。

战报只含本人能看到的信息，显示服务保留的最近 100 条记录。本回合私人情报可展开查看；下方“回顾自己的历史视角”可选择步骤，进入当时的静态棋盘后点“回到当前”继续操作。结束后由房主再开一局；右上方菜单包含邀请、玩家在线情况、动画选项、图鉴、玩法与离开房间。房主离开会关闭房间；进行中的对局需先完成，或在自己的回合投降。

右上方菜单可选择完整或简化动画及播放速度；演出时可点棋盘下方“跳过”。文字、角色动作、攻击和受击反馈依次显示，演出结束后继续操作。历史滑条暂时是静态历史视角。若部分画面未加载，可刷新重试；刷新会恢复自己的席位，不会重复执行旧动作。

# 手机访问本地服务

手机与开服务器的电脑连接同一 Wi-Fi/路由网络，在手机浏览器输入电脑的实际局域网地址及端口。启动窗口可能列出多个网卡：请选择与当前 Wi-Fi 同网段的地址，VPN、虚拟机、代理网卡地址不一定可用。不要在手机输入 `127.0.0.1`。

如果打不开，先确认电脑服务器窗口没有关闭，检查两台设备是否互通，以及电脑是否允许本游戏服务通过专用网络防火墙。公共 Wi-Fi 的客户端隔离也可能阻止互访。不要为此关闭整个防火墙。当前交付环境对本机网卡地址的访问返回套接字权限错误，尚无法替代你实际的手机检查。

手机竖屏以完整棋盘和底部操作栏为主；横屏将操作移到右侧。长参数和详细说明在各自面板内滚动。技能说明使用可点击图鉴，不依赖悬停。返回前台会重新同步。没有添加安装 App、后台保活或离线游玩的承诺。

# 自行部署到其他服务器

本地运行不需要云账号。要让异地好友打开同一个地址，需要一台能够持续运行 Node.js 与 C++ 裁判的主机。仓库提供 `Dockerfile`，可在有 Docker 的 Linux 环境中构建运行；当前 Render 公网服务已通过建房、加入、裁判行动和 SSE 同步检查。

```text
docker build -t mistforest-web .
docker run --rm -p 8787:8787 --name mistforest-web mistforest-web
```

部署前先确定玩家地区、预计同时在线房间数、预算和访问地址，再配置 HTTPS、进程管理及必要的持久恢复。不要把原生裁判管道或调试接口对公网开放；只有网页 HTTP 服务需要对外接入。后端不能由纯静态网页托管代替。

一个可选入口是腾讯云轻量应用服务器的 Docker 镜像，操作参见[官方容器说明](https://cloud.tencent.com/document/product/1207/60329/)。这只是可部署环境示例，不代表已经选定供应商或购买套餐，也未给出未测量的容量承诺。

通信实现参考：[Node.js 子进程](https://nodejs.org/docs/latest-v24.x/api/child_process.html)、[MDN 服务端推送](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events/Using_server-sent_events)、[MDN Fetch](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch)。
